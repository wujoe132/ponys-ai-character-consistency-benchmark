# Ponys Multilingual AI Character Consistency Benchmark

A preregistered, reproducible test instrument for evaluating AI character consistency, memory, identity and voice across seven locales.

- 140 fixed test cases
- Three independent clean-session runs planned per case
- Result state: **not collected**
- This repository does not contain a product ranking
- License: CC BY 4.0

## Multilingual research feeds

The `feeds/` directory contains ten RSS 2.0 distribution feeds for independent research aggregators and publishers: English, Japanese, Korean, Latin American Spanish, Brazilian Portuguese, French, German, Italian, Indonesian and Traditional Chinese. Each feed carries the same preregistered instrument, DOI, first-party disclosure, and `not_collected` result state in its own distribution language. The OPML bundle is available at `feeds/ponys-research.opml`. These feeds are distribution metadata; they do not modify the Ponys.ai product.
